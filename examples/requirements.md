# 可直接试跑的需求样例

把下面任意一条贴进界面左侧的「需求描述」，或直接作为 `main.py` 的第一个参数。

## 想看「回炉修复」循环时用这条（推荐演示用）

写一个函数，返回列表中最大的元素。假设输入列表非空，不需要做参数校验。

需求里明说"不做参数校验"，编码 Agent 交出来的第一版通常直接 `max(numbers)` 或取
`numbers[0]`；探针用空列表一调就崩，报 Major → 进修复 Agent → 第二轮补上校验后通过。
实测轨迹：`code → analyze（并行）→ fix → analyze（并行）→ done`，2 轮、2 个代码版本。

> 反过来，如果需求里**要求**处理空列表，编码 Agent 第一版就会写
> `raise ValueError`，那是正确行为（会被判 Minor 而不是 Major），基本一轮通过。
> 想看循环就得让第一版真的有缺陷。

## 边界处理类

写一个 Python 函数，接收整数列表并返回平均值；空列表返回 None。

## 字符串处理类

写一个 Python 函数，统计一段英文文本中每个单词出现的次数，忽略大小写和标点，
返回按频次降序排列的前 10 个单词。

## 数据结构类

写一个 Python 函数，合并两个已排序的列表并保持有序，要求时间复杂度 O(m+n)。

## 文件 IO 类

写一个 Python 函数，读取一个 CSV 文件并按指定列求和，需要处理文件不存在和
列名为空的场景。
